# Guia do usuário — EducaMais+

## Criando sua conta

1. Na tela inicial, clique em **REGISTRAR**.
2. Escolha seu papel: **Aluno**, **Professor/Tutor** ou **Responsável**.
3. Preencha nome, email e senha (mínimo 6 caracteres) e confirme a senha.
4. Você será direcionado automaticamente ao seu painel.

## Ferramentas de acessibilidade (disponíveis mesmo antes do login)

No menu **☰ MENU** (canto superior esquerdo):
- **Leitor de tela** — ativa a leitura em voz alta (usa a Web Speech API do navegador).
  Nas páginas de materiais, use o botão 🔊 para ouvir o conteúdo.
- **Ajuste de contraste** — alterna para um tema de alto contraste.
- **Ajuste de fonte** — três tamanhos (A-, A, A+).

Essas preferências ficam salvas no seu navegador e, se você estiver logado, também podem
ser salvas no seu perfil (tela **Perfil**) para valerem em qualquer dispositivo.

## Se você é Aluno

- **Painel:** atalhos para Meus Materiais, Necessidades, Fórum e Progresso.
- **Biblioteca:** pesquise materiais por texto, assunto ou tipo (vídeo/texto/atividade).
  Favorite os que quiser rever depois.
- **Atividades:** responda às questões diretamente na tela; o sistema informa se acertou.
- **Progresso:** veja as avaliações que seu tutor registrou sobre você.
- **Fórum:** converse com colegas e tutores nos canais disponíveis.

## Se você é Tutor/Professor

- **Disponibilizar material:** na Biblioteca, clique em **+ Disponibilizar material** para
  publicar vídeos, textos ou atividades. Todos os alunos são notificados automaticamente.
- **Avaliar Aluno:** registre observações e um percentual de progresso para cada aluno;
  o aluno é notificado e passa a ver essa avaliação na tela de Progresso.
- **Fórum:** apoie os alunos tirando dúvidas nos canais.

## Se você é Responsável

- **Progresso familiar:** informe o ID do aluno acompanhado (peça ao aluno ou tutor) para
  ver as avaliações registradas.
- **Sugestões / Biblioteca:** veja os materiais disponíveis para reforçar o aprendizado em casa.
- **Fórum:** converse com professores e outros responsáveis.

## Dúvidas frequentes

**Esqueci minha senha.** Nesta versão de demonstração não há recuperação de senha por
email; crie uma nova conta ou peça para o administrador redefinir diretamente no banco.

**O leitor de tela não fala nada.** Verifique se o navegador suporta a Web Speech API
(Chrome e Edge funcionam bem; alguns navegadores mobile têm suporte limitado) e se o som
do dispositivo está ativo.

**Não consigo publicar material.** Só contas com papel **Tutor** podem publicar; verifique
qual papel você escolheu no cadastro.
