EducaMais+

Educação inclusiva, ao alcance de todos

Plataforma web que centraliza recursos educativos adaptados — vídeos, textos e atividades interativas — para estudantes com necessidades especiais, com ferramentas de acessibilidade e uma comunidade de apoio entre alunos, tutores e responsáveis.

Sobre o projeto

No Brasil, muitos estudantes com necessidades especiais enfrentam dificuldades para acessar materiais educativos adaptados às suas necessidades, o que limita suas oportunidades de aprendizado e inclusão. O EducaMais+ propõe uma aplicação web que centraliza esses recursos, facilitando o acesso a materiais didáticos, atividades interativas e ferramentas de apoio — promovendo uma educação mais inclusiva e equitativa.

    USERS {
        int id PK
        string name
        string email
        string password_hash
        string role "aluno | tutor | responsavel"
    }
    PROFILES {
        int user_id PK_FK
        string necessidades
        string font_size
        bool high_contrast
        bool screen_reader
    }
    RESOURCES {
        int id PK
        string title
        string type "video | texto | atividade"
        string subject
        int created_by FK
    }
    FAVORITES {
        int user_id PK_FK
        int resource_id PK_FK
    }
    FORUM_CHANNELS {
        int id PK
        string name
    }
    FORUM_MESSAGES {
        int id PK
        int channel_id FK
        int user_id FK
        string content
    }
    NOTIFICATIONS {
        int id PK
        int user_id FK
        string message
        bool read
    }
    STUDENT_EVALUATIONS {
        int id PK
        int tutor_id FK
        int student_id FK
        int progress
    }
